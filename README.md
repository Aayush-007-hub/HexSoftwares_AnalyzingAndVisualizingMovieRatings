# Movie Ratings Dashboard

This project is a simple data analysis and visualization dashboard built using Python and Streamlit. The goal of the project was to explore movie ratings data, understand rating trends, and present the findings in a clean interactive dashboard.

I used a movie dataset containing IMDB ratings and genres, then performed preprocessing, statistical analysis, and visualizations to better understand the data.

## Features

- Dataset preview
- Average, median, and highest IMDB ratings
- Ratings distribution graph
- Top rated movies
- Genre-wise average rating analysis
- Boxplot visualization
- Interactive dashboard using Streamlit

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit
